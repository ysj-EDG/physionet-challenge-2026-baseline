## 二、先核验完整数据路径和特征定义

检查真实路径：提取函数 -> 清洗/补零 -> NPZ保存 -> NPZ读取 -> _build_tensors -> collate与时间对齐 -> LSTM及静态分支；另检查推理的原始提取、缓存读取、校准等分支。列出每一个nan_to_num、补零、clip、log、单位换算、标准化、缺失回退的位置及源码行号。

当前公开代码的待核对结构：
- X_seq: (T,483)。EEG频谱54 + coherence360 + BSR18 + EMG24 + Resp14 + 阶段/事件13。
- X_ecg: (W,12)。11项HRV + circadian_cos。
- x_static: (196,)。人口学10 + CAISR186。
- LSTM每个时间步接收483+12=495维，静态196维在分类头处融合。该结构本轮不改。
- 使用 `per_epoch_feature_names()` 和各模块常量建立精确顺序。对静态CAISR的列表、extend与循环逐项展开，不以猜测名称填满维度。

必须特别核对以下线索，以下结论只适用于相应版本的提取器，不能直接套到历史NPZ：
- EEG每通道9项频谱中8项已是log10，另1项为SEF50。负值可能完全正常，不应再做log1p或log1p(abs(x))。
- coherence既有均值/IQR/归一化熵，也有频带积分、频带比值、频谱重心与带宽。不能把360项统一视为0–1。
- BSR当前公式乘100，阈值5/10/20是原始幅度的微伏阈值；输出百分比与阈值单位是两回事。检查缓存是否已除100。
- HRV_MedianNN以ms计；pNN20通常以百分数计；LF/HF功率的两个特征已取自然对数。必须结合本地NeuroKit实现/版本确认，不凭命名猜测。
- EMG已有基线参照的幅度量、已取log的量、比例与每分钟事件率。
- Resp已有局部幅度归一化，同时包含比值、呼吸频率、比例、秒数及有正负号的相关性/时滞。
- 阶段/事件13维是5项阶段one-hot和8项事件覆盖比例，不是13项one-hot。
- 人口学年龄、BMI可能保留原值；性别/种族是类别编码。
- CAISR的n1_pct等当前由分子/分母得到0–1，并没有乘100；不能因后缀pct就统一除100。CAISR还包含秒数、次数、次/小时、概率、熵、比值、前后半夜差值及可为负的复合指标。
- 训练和推理的年龄评估输入必须追踪到原始年龄，不能因模型特征变换而被原地修改。

输出 `feature_schema.json`：每列至少包含 branch、index、name、family、source_file、source_line或函数、formula_summary、unit、expected_domain、existing_transform、zero_semantics、missing_policy、confidence。索引从0开始；未知项明确写unknown及原因。精确匹配483/12/196维和缓存顺序；任何不一致单独报告，不强行reshape或truncate掩盖。

## 三、缓存版本与可识别缺失的审计

逐文件只读检查key、shape、dtype、实际记录身份映射、时间长度、mask长度和已有元数据。检查重复患者/记录、缺缓存、读取失败、模态缺失、静态回退，以及同目录混入不同提取版本的风险。没有版本字段时，不能用文件修改时间或一个范围特征证明版本一致。

把三个层面分开：
A. 真正的NaN/Inf或明确缺失标记。
B. 从源数据可用性、已有日志/质量标志可证实的缺失，但缓存已被补零。
C. 仅看NPZ无法区分的零值：保留为unknown，不擅自恢复为NaN。

正常零值包括无事件、BSR为0、one-hot为0、合法相关/差值为0等，不得统一当作缺失。缓存NaN率为0也不能写成“没有缺失”。

检查现有mask的真正含义：它可能只表示ECG时间对齐，不表示EEG质量或每个HRV窗口的计算成功。不得用ECG的前10个epoch无对齐去排除同期有效EEG。HRV前11维全零可能提示计算失败，但单凭这一模式只能列为启发式标记，除非与源日志或函数状态核实；circadian_cos非零不代表HRV有效。

默认只审计缓存。若当前脚本、元数据和缓存无法判明是否已经缩放，优先核对缓存生成代码及历史配置；仍不能判明时，在数据可用且代价可控的情况下，至多选3个训练集记录做“当前提取值与旧缓存”的只读比对，临时结果写独立目录，不能覆盖旧缓存。区分版本差异、数值容差和真正缩放。若单记录提取耗时明显过长，则跳过并报告未验证内容，不扩展为全量重提取。

## 四、逐列分布与旧裁剪损失

先用小批缓存验证脚本，再对已明确的目标缓存流式扫描；不将6600条整夜序列一次性堆入内存。不修改生产文件，不使用GPU。

每列输出：
- 记录数、总观测数、有效观测数、padding/未对齐数、NaN数、正负Inf数、可识别缺失数及未知缺失标记。
- finite条件下的零值率、负值率、恰好等于-50/+50的比例，以及严格小于-50/大于50的比例。分母与观测类型必须写清。
- min、p0.1、p1、p5、p25、p50、p75、p95、p99、p99.9、max、均值、标准差、IQR。
- 在同一批观测上，旧版清洗裁剪前后分位数/标准差/IQR、边界堆积比例、是否近常量或完全常量；对离散列列出主要取值及频数。
- 裁剪损失按“真实有限值被压平”和“非有限值被补0”分别报告，不能合成一个比例。
- 训练记录中，每个记录的受影响比例分布，避免全体平均掩盖少数记录损坏。
- 理论域违规，如应为0–1却超过1、应为非负却大量负值。先核对定义和单位，不能自动删改。

全量有限性计数、零值计数、clip计数及极值应尽量精确；分位数允许可复现近似，但注明抽样方法、种子、样本量和近似性质，不写成精确结果。
序列列同时区分：所有有效epoch加权的统计，与受试者均衡的统计。建议每记录最多均匀抽取256个有效epoch，抽中的观测按每记录总权重相同进行加权；短记录不能因此自动权重更低。每列有效值不足时记录实际权重。ECG单独从其有效时间窗抽样。静态每记录一次，若同患者多记录，标记并说明统计权重，不自创诊断分组。

结果按全局、站点、已有训练/验证角色分开输出。站点范围差异仅用于质量诊断；不使用I0004/I0007补充数据或外层留出站点拟合参数、选阈值、选择最佳变换。
本轮不按结局标签排序特征，不做单变量AUC筛选，不基于外层测试结果删特征。

## 五、仅做候选变换的离线预览，不接入正式模型

若存在已确认的训练manifest，只用该训练角色的数据拟合候选参数。若本地已有LOSO外层和内层划分，严格在对应内层训练部分拟合；外层测试不参与。若没有明确的训练身份，本步骤跳过，报告“缺少可核验训练manifest”，不得默认用全部6600条拟合。

仅对定义明确、缺失策略明确的列预览：
A. 当前旧clip流程，作为损失参照。
B. 单位统一 + 连续列训练集均值/标准差缩放。
C. 单位统一 + 连续列训练集中位数/IQR缩放。
D. 只对有充分依据的未取log非负长尾列做log1p(x/u)，再稳健缩放；其余与C保持相同。

其中u是写入schema的固定物理参考单位，不得逐患者或逐站点随意改变。已取log的特征不重复取log；有符号特征不能取绝对值后当成非负处理；比例与类别编码不强行正态化。
BSR/pNN20等仅在确认缓存仍为0–100时除100；本来0–1的pct保持不变。单位换算本身和统计缩放是两个步骤，分别记录。
对IQR=0/极小、零膨胀、全常量、全缺失分别报告。禁止用任意1e-8作分母把罕见事件放大到巨大值。未确定的列不强行拟合成功，标为待人工决策，并给出有限的备选方案，如保持物理尺度或采用训练统计的替代尺度。
变换预览先不增加新的截断，报告变换后abs(z)>5/10/20/50的比例、有限性及典型分位数，不把这些数值直接认定为最佳clip阈值。比例/one-hot单独报告，不混入连续z分数统计。

只把上述预览当作数值诊断，不能用“更像正态”或“范围更小”宣布最佳方法，也不能写出未经训练验证的AUROC提升。

## 六、正式修复的设计草案（仅写报告，不实施）

说明如何在不改变483/12/196输入结构的情况下增加一个共享变换器：
- 训练折只拟合一次；在加权采样之前基于原始训练记录拟合，不让重复采样改变缩放统计。
- 先识别有效值/单位与类型，做选定单调变换，再按列缩放；缺失填补必须和变换的中心一致。
- 不以每个患者自己的整夜均值/标准差去归一化所有列；不跨不同特征做每行归一化。
- 对缺失语义不明的旧缓存，写明是否需要重提取或新增质量信息，不能声称缩放能恢复丢失的信息。
- padding与未对齐占位不进入fit；先对真实有效数据transform，再填充模型所需的零值。实际缺失、padding、无事件不是同一个概念。
- 训练、验证、推理、缓存与原始提取分支共用同一实现且只变换一次。
- checkpoint保存或严格引用带校验和的schema版本、特征顺序、单位、变换类型、中心/尺度、缺失策略、常量列规则及训练记录集合摘要。载入时做一致性校验；不能把新scaler接到旧权重上继续推理。
- 官方指标保留原始年龄副本，不对其进行原地变换。
- 新增给模型的缺失指示维度属于另一项消融，本轮不得悄悄追加而改变架构。
